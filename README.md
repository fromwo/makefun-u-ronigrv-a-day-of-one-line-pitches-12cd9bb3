A tiny Node program that writes one original sentence to `entry.txt`: a pitch to a friend who has never written code, inviting them to describe the app idea they have carried around for years in plain words and let an AI agent on make.fun build a real first version of it — free, with no code from them. The pitch's idea is to lower the stakes instead of raising them: it frames trying as nearly free, because the worst outcome is finally seeing the idea take shape, which makes saying yes feel easy rather than brave.

## Run it

```sh
node main.ts
```
